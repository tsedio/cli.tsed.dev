What is Ts.ED?

Ts.ED offers a flexible structure with a fast learning curve, specifically designed to improve the developer experience. It provides numerous decorators and guidelines to make your code more readable and less error-prone. Ts.ED supports various platforms and tools, including Node.js/Bun.js, Express.js/Koa.js/Fastify.js, CLI, and

Multi-platform

Easily build your server-side application using Express.js, Koa.js, Fastify.js, CLI, or serverless platforms (e.g., AWS). It supports both Node.js and Bun.js runtimes. Learn more about Ts.ED capabilities.

AI-forward

Resources and integrations to supercharge your development with AI. Learn how to develop with AI and speed up your project setup with the AGENTS.md template (Codex, Junie, etc.).

CLI

Build interactive workflows with @tsed/cli-mcp, @tsed/cli-prompts, and @tsed/cli-tasks. Head to the CLI docs to see how the runtime, prompts, and task orchestration fit together.

Plugins

Explore a variety of plugins (+100) to customize your application and build the perfect stack tailored to your needs. You can even create your own plugins to extend functionality further.

Class-based & Decorators

Define classes as Controllers, ConfigSource, Models, Providers (DI), Interceptors, Pipes, and more — and leverage a wide range of decorators to structure your code, define routes, and implement methods with ease. JSON Schema and OpenAPI are at the core of the framework.

Testing

Testing is not optional - it's essential! Ts.ED includes built-in features to make testing your code simple and efficient. Learn more about testing tools embed by Ts.ED.
